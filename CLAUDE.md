# PROTEAN

A small loop around Claude Code: a thinker seat moves a thought forward one move at a time (ideas, explore, task, ask, rest), a contained editor does each unit or explore in a clone, a grader verifies units, a console (a local API inside the brain, `protean ctl …` in the terminal) carries the operator's thoughts, answers, approvals and extensions. Sessions are thinking sessions; there is no goal mode and no `done`. `README.md` says how to run it and what this public mirror leaves out; `architecture.md` is the what/where/why of the running system.

| Task | Go to |
|---|---|
| Change the loop, the tick order (`loop.TICK`), resume or abandon | `src/protean/loop.py` |
| Change what the thinker is sent, how a move is decoded, or the no-progress rule | `src/protean/graph/director.py` (the seat key stays `director`), prompt `brain/protean/thinker.md` |
| Change how an explore runs | `src/protean/graph/worker.py` (`run_explore`), `src/protean/loop.py` |
| Change the editor's containment, clone or branch handling | `src/protean/graph/worker.py`, prompt `brain/protean/editor.md` |
| Change a predicate kind or how a unit passes | `src/protean/graph/grade.py` |
| Change how a branch of retained predicates is admitted, which paths a command protects, or what the reader is asked | `src/protean/graph/gate.py`, `src/protean/graph/reader.py`, prompt `brain/protean/reader.md` |
| Change a ceiling, a cap, a seat's model or cost accounting | `src/protean/graph/budget.py`, `src/protean/runner.py`, `brain/protean/config.json` |

| Add a dry scenario | `fixtures/protean/<scenario>/`, `src/protean/dry.py` |

Rules:

- Every model call goes through a `Runner`; tests inject scripted runners and the shim on PATH fails any test that reaches the real binary.
- Only `grade.grade()` sets a unit `passed`. A director reply never carries a status. An ungradeable predicate never passes. A unit whose branch carries no change delivered nothing and is ungradeable, so a predicate satisfied by pre-existing files cannot pass. `file_exists` and `file_contains` read the branch's tree objects, never the working tree: only a committed regular file counts, and a symlink, a directory, a nested repository, an ignored path or anything under `.git` never does.
- A unit's `needs` must pass and be integrated before it runs; a need that fails makes its dependents `blocked`. Decode rejects an unknown need, a self-need and a cycle.
- `task/<task>` in the workspace is the accepted work: every unit branches from its tip, and it moves only by a checked `update-ref` fast-forward to a candidate that passed its own predicates and every integrated unit's RETAINED `file_exists`, `file_contains` and `command` predicates (`retain` defaults to true; a `retain: false` predicate must pass its own unit's grade and is never re-checked after). A retained predicate leaves the re-check set only by branching: a unit whose predicates name it as a parent is admitted by one fresh reader call, its own candidate is excused from that parent once every child passed (recorded `excused`, never `broke`), and at its integration the parent is retired for good. A retained `command` must name `protected` paths at decode; a candidate that passed every free check and touched one of an accepted command's protected paths is integrated only after one reader call says the checks are not weakened (`weakened` or no verdict rejects the attempt; untouched costs nothing). The grade, the re-checks and the weakening diff run in the grading clone, a fresh clone of the workspace at the candidate, never in the editor's clone, and count only if that clone still sits clean on the candidate afterwards (a check command that moves HEAD or leaves a file fails the attempt). Branch admission is decided once per plan, by the mode its director call started in. A pass saves `passed` + `candidate` first, then moves the ref and saves `integrated`; a tick or resume finishes a cut pass without re-running the worker, and a ref moved outside the loop parks the task on a question instead (`--abandon` still closes it). `main` is never checked out, moved or merged into.
- A `command` predicate runs under `sandbox-exec`: no network, writes only inside the clone, uv's caches and the temp dirs, no read of the task's `console.json`. Without the sandbox binary it is ungradeable; a check command never runs unconfined.
- A model call interrupted mid-flight (Ctrl-C, SIGTERM, SIGHUP or any exception) books its spend on the task and saves before the interruption propagates: the clipped `--max-budget-usd` while the call runs, the receipt's cost once it has returned. The CLI exits 130 and `protean resume` continues the task. Every call is recorded in `task.json` BEFORE it launches (`Call`: seat, attempt, cap, charge vs receipt cost, tokens, message size, session, outcome); a SIGKILL leaves that record `pending`, and `resume` books it once at its reserved cap, records the actual spend `UNKNOWN`, and parks the task on a `runtime:` question before any further paid call — `yes` continues under the uncertainty. Unavailable measurements are null, never 0.
- A bug fix lands its repro test first. Behaviour a landed test pins changes only with the operator's word.
- Nothing spends without the operator's go. `protean think` and `protean resume` spend on a real workspace.
- `brain/protean/state/` is runtime state, never hand-edited; questions, thoughts, the thought record (`thought.md` is a rendered view of `task.json`, never edited) and the console's port/token file live there. `mode` is `auto` or `hold` per session (`protean ctl mode hold`): hold waits for `protean ctl approve` before a task move's units enter the session, before a retry attempt and before an explore — never before the ref move; a think while something is held returns it to the thinker. After `ideas` or `rest` the session waits for a think. `decided` is written only by a console think with `--decide`. The editor's transcript streams to the console only. Answer, think and extend through `protean ctl` (live brain or offline against `task.json`), never by editing the file. The editor's sandbox denies reading `console.json`; the token never enters a child's env or argv.
